# Clout City NYC

> Tap in. Blow up.

A mobile-first browser life game: arrive in New York as a nobody and chase clout.

**Current version: v0.1 "Tap In"** — an early-access teaser. Browse the Queens night
map as a guest, sign up with an email magic link (18+), claim a name and a starting
style for your 3D character, see them at home, and invite your clique before the
city opens.

- Setup (Supabase, email template, Vercel): [`docs/SETUP.md`](docs/SETUP.md)
- Specs and the version plan: [`docs/`](docs)
- Working notes for contributors and Claude Code: [`CLAUDE.md`](CLAUDE.md)

```bash
npm install
npm run dev        # http://localhost:3000 (guest map works without Supabase)
npm test           # unit tests
npm run build
```
